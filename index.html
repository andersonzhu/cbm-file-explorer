Open a CBM report file

      
Drop a THECB CBM submission file anywhere on this page, or choose one. The explorer reads the HY2K header record, picks the matching record layout, and splits every record into named columns you can filter, sort, edit and copy into Excel.

      
Files are read inside this browser tab. Nothing is uploaded.

      

      

    

  









  

    

      
Record layouts
A layout lists where each field starts and how many characters it takes. The built-in layouts come from the THECB manual. Add your own for older files or any other fixed-width report.

      
    

    

    

      Share layouts you’ve made
      

        
Layouts you make are saved in this browser only. Copy the export and send it to a colleague, who pastes it below and chooses Import. To build layouts into this file for everyone, paste the export between the office-layouts script tags near the top of the HTML file.
